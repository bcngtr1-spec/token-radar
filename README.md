Pre-Token Radar: ranks 758 pre-token DeFi protocols by implied value derived entirely from a live TVL snapshot (TVL × category multiple × 7-day growth × maturity × chain reach), with a confidence score, a concrete farm plan per protocol, and a sortable dark-mode dashboard with watchlist filtering and per-protocol detail drawers.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
